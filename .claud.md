# Internship Tracker - AI Agent Context

## Project Overview
Full-stack web application for tracking Summer 2026 internship applications. Parses data from the SimplifyJobs/Summer2026-Internships GitHub repository and provides a web interface for filtering, tracking applications, and managing resumes.

## Architecture

### Backend (FastAPI + SQLite)
- **Location**: `backend/`
- **Entry Point**: `backend/main.py`
- **Port**: 8000
- **Database**: SQLite (`data.db` in project root, auto-created on startup)

### Frontend (Vanilla JS)
- **Location**: `frontend/`
- **Entry Point**: `frontend/index.html`
- **API Base**: `http://localhost:8000/api`
- **No build step**: Open HTML directly or serve via `python -m http.server`

### Data Source
- **Location**: `Summer2026-Internships/` (git submodule)
- **Parser**: `Summer2026-Internships/parse_internships.py`
- **Output**: 5 CSV files (one per category)
- **Total Jobs**: ~5,749 internships

## Important Implementation Details

### Job ID Generation
- **Format**: `{company}|{role}|{location}|{date_posted}`
- **Location**: Backend `main.py:57-58`
- **Usage**: Unique identifier for tracking applications
- **Warning**: Contains pipe characters - must use `encodeURIComponent()` for API calls, NOT HTML escaping

### Event Handling Pattern
- **DON'T**: Use inline `onclick` with `escapeHtml()` - breaks job_id
- **DO**: Use data attributes (`data-job-index`) with event delegation
- **Why**: HTML entity encoding corrupts pipe characters in job_id

### URL Structure
- Each job has TWO URLs:
  - `application_url`: Full Simplify tracking URL
  - `base_url`: Cleaned URL without tracking parameters
- Both stored in CSV, both displayed in UI

### Resume Deduplication
- Uses SHA-256 content hashing
- Files stored as `{hash}{extension}` in `resumes/`
- Database tracks: hash, original_filename, file_path, upload_date
- Automatic duplicate detection on upload

## Common Issues & Solutions

### Issue: 404 errors on `/api/internships//apply`
**Cause**: job_id is undefined or empty
**Debug Steps**:
1. Check console for "Invalid internship data" error
2. Verify backend loaded CSV files correctly
3. Restart backend to reload CSVs
4. Hard refresh frontend (Cmd+Shift+R)

### Issue: Only ~500 jobs instead of 5,749
**Cause**: Parser still has 7-day filtering OR backend using old CSVs
**Fix**:
1. Verify `parse_internships.py` lines 249-250 have no date filtering
2. Re-run parser: `cd Summer2026-Internships && python3 parse_internships.py`
3. Restart backend

### Issue: Changes not reflecting
**Solutions**:
- Backend: Restart the server (Ctrl+C, then `python main.py`)
- Frontend: Hard refresh (Cmd+Shift+R) or clear cache
- Database: Delete `data.db` to reset

## API Endpoints

### Core Endpoints
- `GET /api/internships` - Get all jobs (with filters)
  - Query params: category, date_from, date_to, location, company, is_faang_plus
- `POST /api/internships/{job_id}/apply` - Mark job as applied
- `POST /api/resumes/upload` - Upload resume (multipart/form-data)
- `GET /api/resumes` - List all resumes
- `POST /api/refresh` - Git pull + re-parse data

### Helper Endpoints
- `GET /api/categories` - List available categories
- `GET /api/stats` - Get statistics
- `GET /docs` - FastAPI auto-generated docs

## Database Schema

### Applications Table
```sql
CREATE TABLE applications (
    id INTEGER PRIMARY KEY,
    job_id TEXT UNIQUE NOT NULL,
    applied BOOLEAN DEFAULT FALSE,
    resume_hash TEXT,
    applied_date TEXT,
    notes TEXT,
    FOREIGN KEY (resume_hash) REFERENCES resumes(hash)
)
```

### Resumes Table
```sql
CREATE TABLE resumes (
    hash TEXT PRIMARY KEY,
    original_filename TEXT NOT NULL,
    file_path TEXT NOT NULL,
    upload_date TEXT NOT NULL
)
```

## Critical Code Patterns

### Loading Internships (Backend)
```python
# MUST generate job_id for each internship
job_id = f"{internship['company']}|{internship['role']}|{internship['location']}|{internship['date_posted']}"
internship['job_id'] = job_id
```

### Rendering Table (Frontend)
```javascript
// Use data-job-index, NOT inline onclick with job_id
filteredInternships.map((internship, index) => `
    <input type="checkbox"
           class="apply-checkbox"
           data-job-index="${index}">
`)

// Event listener reads index, gets job from array
const index = parseInt(this.dataset.jobIndex);
const internship = filteredInternships[index];
toggleApplied(internship.job_id, this.checked);
```

### API Calls (Frontend)
```javascript
// ALWAYS encode job_id for URL
fetch(`${API_BASE}/internships/${encodeURIComponent(jobId)}/apply`)

// NEVER use escapeHtml() on job_id before encoding
```
